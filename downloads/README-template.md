# 我的定投研究项目（教学模拟）

## 研究问题
在同一模拟时间区间、同一每月投入、同一交易时点下，四种新资金分配比例的账户结果与风险有何区别？这不是对真实资产未来收益的预测。

## 运行
需要 Python 3.10 或更高版本。在本目录打开终端：

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS / Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python backtest.py --self-test
python backtest.py
```

结果保存在 `results/`：四组逐日账本 CSV、`summary.csv`、`comparison.png`。网站不在浏览器执行 Python。若系统命令是 python3，请将命令中的 python 换为 python3。先确认终端当前目录与文件所在目录一致。

## 数据来源与范围
`sample_prices.csv` 为确定性公式合成的教学数据，不是标普500、纳斯达克100、基金或其他真实行情。日期为 2021-01-01 至 2024-12-31 的星期一至星期五，没有剔除交易所节假日。首行注释用 `pd.read_csv(..., comment='#')` 跳过。

令 i 为从 0 开始的行序号：
- A = 100 × exp(0.00022i + 0.16sin(i/83) + 0.035sin(i/9) − 0.28exp(−((i−440)/85)²))
- B = 100 × exp(0.0001i + 0.055sin(i/110+0.7) − 0.035sin(i/19))

价格四舍五入到 6 位小数。两组名称仅代表两条合成价格路径。替换成真实行情前必须检查授权、分红拆分复权、币种、频率与完整交易日历。

## 策略假设
每月第一个可用数据日收盘投入 1000 单位货币；先计算旧份额当日涨跌，再以收盘价购买。四组 A/B 新资金比例为 100/0、80/20、60/40、0/100；这只是实验参数，不是投资建议。可买小数份额，无费用、税、滑点、分红或汇率；不卖出，不对已有持仓再平衡。月度比例约束新资金，已有资产权重会漂移。

## 指标口径
- 账户收益额 = 期末资产 − 累计本金；简单收益/本金没有处理时间差，不能称年化收益。
- 每日剔除入金收益 = 当日入金前市值 / 上日入金后市值 − 1。第一天净值定为 1。
- TWR 年化 = 期末净值^(365/实际日数) − 1，度量现金流调整后的策略表现。
- 年化波动 = 日收益样本标准差 × √252；252 是教学近似，依赖等频日数据，不适合直接套在月数据。
- 最大回撤 = min(净值 / 此前最高净值 − 1)，以负数报告。它是样本内风险，不是未来损失上限。
- XIRR 对负投入、最后一次正结算按实际天数/365 求根，属于投资者资金加权年化收益。只支持这种常规定投现金流，无有效期限或数值解时显示“不可计算”。
- 单笔买入持有的 CAGR = (期末值/初始值)^(365/实际日数)−1；不能将累计本金替换初始值来计算定投 CAGR。

## 填写观察
1. 哪组期末资产最高？同时列出本金、收益額、XIRR。
2. 哪组净值最大回撤最深？具体高点到低点的日期是什么？
3. 把每月投入改为 500 后，账户值与净值分别发生什么变化？
4. 结果是否来自路径、区间或数据构造？有什么无法推断？

## 验证与局限
执行 `--self-test` 检验零收益、持续下跌、投入规模变化及 XIRR 日期。区间仅为合成样本；忽略实际摩擦。不能由四组结果选出“永远最优”权重。样本不足两个收益观测时波动率不可计算，CSV 显示“不可计算”而不是填零，并在 volatility_status 列说明样本不足。
